The World in One Day — Tuesday 24 November 2026. One 1024×1024 image that
sums up the day's world news: 26 stories (3 leads, 13 cards, 10 briefs)
across 7 regions, a UTC timeline, a day-in-numbers box with a source on
every figure, a numbered world map, and a DATE CHECK box that lists only
stories left off the page.

## Run it

```sh
node main.ts
```

`main.ts` copies the pre-rendered `entry.png` to `$OUTPUT_DIR/entry.png`
(default `/output`). The image itself is drawn at build time by `draw.py`
(Python + Pillow); `main.ts` never runs it.
